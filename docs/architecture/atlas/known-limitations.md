# Known viewer limitations

The following interaction limitations were observed in the viewer runtime generated by the pinned Archify v2.13.0 release. They affect viewer controls, not the Gantry architecture content represented by the diagrams.

| Artifact | Observed limitation | Safe workaround |
| --- | --- | --- |
| [Fleet execution](./fleet-execution.architecture.html) | With a fine pointer, a relationship hover preview can prevent the following click from pinning or opening that relationship. | Focus the relationship with the keyboard and activate it without first hovering, or use the other focus and search controls. |
| [Live turn](./live-turn.sequence.html) | The transient share cue can be clipped horizontally when animation is disabled or reduced motion is active. The cue is decorative. | Confirm the export from the downloaded file or export control instead of relying on the cue. |
| [Live turn](./live-turn.sequence.html) | An invalid `#route` value can leave the previously selected route visible. | Clear Route Probe, or reload the page without the fragment before applying another link. |
| [Live turn](./live-turn.sequence.html) | A `#lens` value containing no valid kinds can leave the previously selected lens visible. | Clear the lens, or reload the page without the fragment. |
| [Memory and dreaming](./memory-dreaming.dataflow.html) | Clicking the Route Probe toolbar button can clear a focused source node before the probe reads it. | While the node is focused, press `R` to start Route Probe, or select the source after starting the probe. |
| [Memory and dreaming](./memory-dreaming.dataflow.html) | An invalid `#focus` value can leave the previous focus visible. | Clear focus, or reload the page without the fragment. |
| [Memory and dreaming](./memory-dreaming.dataflow.html) | An invalid `#route` value can leave the previously selected route visible. | Clear Route Probe, or reload the page without the fragment. |

## Ownership and update policy

These behaviors belong to the shared viewer template in the tagged `tt-a1i/archify` v2.13.0 generator pinned for this atlas. Archify upstream owns viewer-runtime fixes. Gantry owns this disclosure, the generator pin, and the integrity of its delivery receipts.

Gantry does not carry a local viewer fork. Do not hand-edit the generated JSON or HTML to work around these behaviors. A future Archify upgrade must regenerate and validate the artifacts and update their receipts as one reviewed delivery.
