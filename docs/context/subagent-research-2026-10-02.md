2. **Results can contain only the last streamed fragment.** `latestResult = frame.result` overwrites preceding deltas ([execution:109](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/jobs/ipc-delegated-agent-execution.ts:109)); streaming process completion supplies no accumulated result ([process:623](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/runtime/agent-spawn-process.ts:623)). 4. **Target authorization differs across paths.** Worker checks the caller’s configured delegates ([target:193](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/jobs/ipc-agent-delegation-target.ts:193)); inline generic delegation accepts any bound target ([inline:109](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/app/bootstrap/inline-agent-task-lifecycle.ts:109)). 5. **Worker-to-inline steering falsely succeeds.** Worker IPC writes a filesystem continuation ([handler:580](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/jobs/ipc-agent-task-lifecycle-handlers.ts:580)); inline consumes an in-memory control port ([inline-control:75](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/runtime/agent-inline.ts:75)). ## Engine capabilities and recommended design

**Gantry should keep one host-owned delegation mechanism and add explicit sync and async modes to it.** I would keep native subagent tools disabled. Native features offer useful context isolation, but introducing two more execution lifecycles would complicate permissions, cancellation, recovery and reporting.

This assessment is pinned to **2026-10-02**, Claude SDK **0.3.156** and Deepagents **1.10.2**. I read the audit and installed definitions/source before checking official documentation. No files were changed.

**Recommended Gantry contract**

```ts
delegate_task({
  objective,
  context?,
  targetAgentId?,
  mode: "sync" | "async",
  outputSchema?: JSONSchema,
  deadlineAt?,
  maxTurns?,
  maxCostUsd?
})
task_get({ taskId, waitMs? })
task_list({ status? })
task_message({ taskId, message })
task_cancel({ taskId })
```

Both modes admit a Postgres task **before execution**, launch an isolated child Gantry run, and return one envelope:

```ts
{ taskId, status, summary, output?, artifactRefs?, error?, usage }
```

- **Sync:** wait within the turn and return the terminal result. Parent cancellation cancels its sync children. No silent conversion into background work.
- **Async:** return admission immediately; survive parent completion and deliver a durable completion event to the originating parent/thread. The parent composes the user-facing reply.
- **Output:** validate `outputSchema` before success. Store bounded typed output and receipts on the task; put large results in artifacts/files referenced by the task. File writes do not automatically publish results. Memory updates remain explicit, through Gantry’s existing memory workflow.
- **Control:** persist steering with sequence numbers and acknowledge actual child acceptance. Cancellation targets the host run controller and linked work. Persist absolute deadlines; enforce remaining time after recovery, plus per-child and aggregate parent budgets/concurrency.
- **Authority:** inherit authenticated principal, channel/account/thread and job identity. Same-agent children inherit the caller’s authority envelope; named-agent delegation requires explicit handoff authorization and the target’s permitted envelope. Recovery revalidates authority. Keep one-level delegation initially.
- **Jobs:** inherit autonomous permission handling, job lease and remaining deadline. Children settle into the job report; work outliving the job requires an explicit independent-job handoff.
- **User experience:** one progress surface showing queued/running/waiting-for-permission/terminal states, concise summaries, result links, steering and cancel controls. Child token streams should not flood Slack, Telegram or Discord.
- **Recovery:** fenced ownership, persisted provider handles/checkpoints, deduplicated completion delivery; resume only where supported. Otherwise report interruption rather than replay uncertain side effects.

Keep engine adapters thin: launch, stream, cancel, resume and schema output. Reuse Gantry’s existing [schema validator](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/adapters/llm/inline-lane-dispatcher.ts:176) and both inline adapters. Worker execution currently [rejects response schemas](/Users/ravikiranvemula/Workdir/myclaw/apps/core/src/runtime/agent-spawn-admission.ts:123), so that boundary needs explicit treatment.
